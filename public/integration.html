🔗 Intégrez HATIMEDIA sur votre site

Copiez le code ci-dessous et collez-le juste avant la balise </body> de votre site web. Le widget apparaîtra automatiquement en bas à droite.

<script src="https://hatimedia.onrender.com/widget.js" data-client="hatimedia"></script>

* Remplacez data-client="hatimedia" par l'identifiant de votre client.
